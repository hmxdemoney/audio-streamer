# 电脑系统音频同步

[English](README.md) | 简体中文

这是一个轻量级的系统音频同步工具，可以将您电脑上发出的任何声音，通过局域网实时串流到手机或平板上播放。特别针对 iPhone 和 Safari 浏览器进行了深度优化。

## ✨ 核心特点

*   **开箱即用**：无需安装复杂的客户端，手机端只需使用浏览器即可播放。
*   **专属域名访问 (mDNS)**：苹果设备（iPhone/iPad/Mac）无需输入繁琐的 IP 地址，只需在浏览器中直接访问 `http://audio.local:8000` 即可连接。
*   **主动静音注入技术**：彻底告别“卡带声”！传统网页音频串流在电脑端静音或停止播放时，手机端往往会无限循环播放最后一小段声音。本工具采用“主动静音填补”技术，在电脑无声时主动下发数字静音包，确保极致纯净的听觉体验。
*   **智能设备无缝切换**：当您在电脑上切换音频输出设备（例如从音箱切换到耳机）时，程序会自动侦测并平滑重连，无需重新启动。
*   **支持息屏播放**：完美支持 iOS 系统息屏状态下持续播放。

## 🚀 如何使用

1.  **运行程序**：在您的电脑上运行本程序的执行文件。程序启动后，会尝试捕获当前系统的默认音频输出。
2.  **连接局域网**：确保您的手机（或平板）与运行程序的电脑连接在**同一个 Wi-Fi 网络**下。
3.  **打开浏览器**：
    *   **苹果设备用户 (iPhone/iPad/Mac)**：打开 Safari 浏览器，直接访问 `http://audio.local:8000`
    *   **其他设备用户 (Android/Windows)**：请查看电脑端运行窗口中显示的 IP 地址，例如访问 `http://192.168.x.x:8000`
4.  **开始播放**：在手机网页上点击“开始连接并播放”按钮，即可听到电脑的声音。

## 📱 支持的设备

*   **发送端（运行本程序的电脑）**：支持 Windows、macOS 和 Linux。
*   **接收端（播放音频的设备）**：任何带有现代网页浏览器的设备。强烈推荐使用 **iPhone (iOS) + Safari** 以获得最佳的体验。

## 💡 大概原理

本程序在电脑端运行后，会实时监听系统默认声卡的输出声音。同时，它会在后台启动一个微型的 Web 服务器和 WebSocket 通讯通道。
当您的手机浏览器访问该网页并点击播放时，手机与电脑之间会建立一个低延迟的数据通道，电脑端将捕捉到的声音转换成数据流，源源不断地发送给手机，手机端则利用浏览器的 Web Audio API 将数据流还原成声音播放出来。
